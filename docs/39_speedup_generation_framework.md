## T1. 가속비 (R8-1) — 두 기준선을 나란히

**기준선 선택 규칙.** GPU 가 있는 **그 노드의 CPU** 를 1차 기준선으로 쓴다. 그 노드에 CPU
측정이 없을 때만 교차 노드 기준선을 쓰고 표에 **교차 노드**라고 적는다. 한 행의 두 기준선은
반드시 **같은 기계**에서 온다. `ktcloud` 의 CPU 는 공유 호스트이므로 어느 기준선도 되지
않는다(R7-1) — 그래서 H100 행은 전부 교차 노드다.

## 규칙 준수

- **R8-1**: 모든 배율에 두 기준선(최선 CPU 구성·직렬)과 그 구성의 스레드 수·기계 이름을 병기.
- **R7-1**: `ktcloud` CPU 시간은 어느 기준선도 아니다. H100 행이 교차 노드로 표시되는 이유.
- **R5-1**: 각 표는 `case · scheme · solver · CFL · nz · 스텝수 · 정밀도`가 하나로 고정된다.
  T1 은 `lock_exchange` / fb / CFL 0.5 / nz 30 / 50 스텝 / fp64 다.
- **R12**: GPU 가 지는 칸(0.32×·0.88×)을 그대로 싣는다.

## 한계

- T1 의 RTX 5090 행에 직렬 기준선이 비는 격자가 있다(1000² 이상). 그 노드에서 직렬 실행을
  하지 않은 것이며, 없는 것을 EPYC 직렬로 메우지 않았다 — 그것이 R8-1 이 금지하는 대체다.
- F4 의 2000² JAX 행이 없다(5090 에서 단일 할당 상한, docs/90 N21).
