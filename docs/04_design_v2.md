# 04. 실험설계 v2 — 논문 본체를 위한 2층 구조 (2026-09-11)

> docs/01 은 v1 설계다. 이 문서가 **우선**하며, 충돌하면 이 문서를 따른다.
> v1 에서 측정한 것은 버리지 않고 **1층**으로 재배치한다.

## 0. 논문의 질문 (한 문장)

**동일한 이산화 스펙 위에서, 시간적분 스킴(양해 / semi-음해 / 완전음해 / split-explicit)의
정확도-대-소요시간 프론티어가 컴퓨팅 자원(CPU / 소비자 GPU / 데이터센터 GPU)과
언어·프레임워크(Fortran / OpenACC / CUDA / JAX)에 따라 어떻게 이동하는가.**

## 1. 왜 2층인가

v1 은 깊이가 고르지 않았다. 해법·지형·정밀도·하드웨어 축은 **커널**(변계수 Helmholtz, EOS)에서
2,500행 이상 쟀는데, 스킴 축은 3D 에서 두 수준뿐이고 Python-GPU 는 0건이며 모델 수준 실행은
선형·평탄 바닥이었다. 리뷰어의 첫 반론은 "이건 해양모델이 아니라 Helmholtz 솔버의 벤치마크"다.

| 층 | 대상 | 역할 | 상태 |
|---|---|---|---|
| **1층 커널** | 변계수 Helmholtz · EOS · 통신 | 모델 수준 결과를 **설명**한다 | ✅ 완료 (docs/25–28) |
| **2층 모델** | v0.5 전체 코어의 한 스텝 | 논문의 **본체** | ⬜ 이 문서 |

## 2. 2층의 축과 수준

| 축 | 수준 | 비고 |
|---|---|---|
| **A 스킴** | `fb` · `theta=0.5` · `theta=0.6` · `theta=1.0` · `split_explicit` | 3D 에서 5수준 전부 |
| **B 해법** (θ 계열) | `pcg_jacobi` · `multigrid` | 나머지 해법의 위치는 1층이 준다 |
| **D 백엔드** | `fortran_serial` · `fortran_omp` · `openacc` · `cuda` · `jax` | NumPy 는 오라클 전용, 시간 보고 안 함 |
| **K 하드웨어** | EPYC 9655 (geo85, PBS 배타) · RTX 5090 (gpgpu) · H100 (ktcloud) | CPU 는 **geo85 계산노드**에서. gpgpu 의 16코어는 CPU 대표가 아니다 |
| **E 격자** | 100²·200²·400²·1000²·2000² × 30층 | 3×10⁵ → 1.2×10⁸ 셀. H100 80 GB 상한 |

| **C 케이스** | ① `baroclinic_igw` 지형 위 (해석해 없음 → 수렴 기준해)<br>② `basin_seiche` 닫힌 분지 순압 (활성 순압 모드)<br>③ `lock_exchange` (비선형, RPE) | ②가 스킴을 **정확도**로 가른다 |
| **G 정밀도** | fp64 (본체) · fp32 (1절) | |
| **물리** | v0.5: 지형(z-level 부분셀) · 닫힌 벽 · 이류 · T/S · TEOS-10 · 수평 점성 | 컴파일 백엔드는 z-level 만. z\*/σ 는 Python 결과(docs/24)로 충분 |

## 3. 부분 factorial — 두 조각

완전조합 5×2×5×3×5×4×3 은 불가능하다.

**조각 S (스킴 이야기):** 스킴 × 해법 × dt × 케이스 — **격자 400²×30, 노드 gpgpu(RTX 5090)**
고정. 파레토 평면(오차 대 소요시간)이 여기서 나온다. CPU 곡선은 같은 노드의 16코어로 병기하되
CPU 대표는 아니다.

**조각 H (하드웨어 이야기):** 백엔드 × 하드웨어 × 격자 — **스킴 두 개**(조각 S 가 고른 최선·최악)
× 케이스 ① 고정. 세 노드에서 같은 이진 문제를 푼다.

**CPU 대표 = geo85 계산노드 (EPYC 9655, `place=excl`)**, 스레드 수는 격자별 최적(docs/25 §5)을
쓰고 직렬 빌드를 기준선으로 병기한다.

## 4. 지표

1차: **고정 오차에서의 소요시간** — 케이스별 기준해 대비 상대 L2 가 문턱(1e-3) 아래인 구성 중
`sim_days_per_wall_day` 최대. 파레토 평면에 전 구성을 찍는다.
2차: 셀·스텝당 ns, 로프라인 위치, 에너지(가능한 노드).
보고 규칙: R8 · R8-1 (양쪽 기준선 명시).

## 5. 규칙 개정

- **R7-1 개정.** 노드 간 비교 금지는 "CPU 를 다른 노드 GPU 의 *대리 기준선*으로 쓰는 것"에만
  적용한다. **두 장치 자체가 비교 대상**(EPYC 9655 대 H100)이고 문제가 바이트 동일하며
  반복수가 일치하면 허용하고 장치명을 그 문장에 적는다.
- **R7-2 준수.** 커널 벤치가 3회·최솟값을 썼다. 5회·median+MAD 로 고친다.
- **R6 준수.** 컴파일 벤치도 manifest(git SHA·컴파일러·플래그·호스트)를 남긴다.
