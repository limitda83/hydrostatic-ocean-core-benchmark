## 1. Phase 0 지배방정식 — 선형 회전 천수방정식

f-plane, 평평한 바닥(수심 `H` = const), 마찰·점성 없음:

```
∂u/∂t − f v = −g ∂η/∂x          (운동량 x)
∂v/∂t + f u = −g ∂η/∂y          (운동량 y)
∂η/∂t + H ( ∂u/∂x + ∂v/∂y ) = 0  (연속)
```

- `η` : 자유수면 변위 [m], `u,v` : 수평 유속 [m s⁻¹]
- `g` : 중력가속도, `f` : 코리올리 파라미터, `H` : 정지 수심
- 순수 중력파 속도 `c = sqrt(gH)`, 로스비 변형반경 `R = c / f`

> 이 계는 해석해를 갖고 **모든 스킴·백엔드의 검증 하네스**가 된다.
> Phase 2에서 3D 정역학 원시방정식으로 확장한다 (§7).

## 2. 공간 이산화 — Arakawa C-grid

균일 격자 `dx = Lx/nx`, `dy = Ly/ny`. 변수 배치 (셀 `(i,j)` 기준):

```
        v[j, i]  (i, j+1/2)
           ^
           |
  ---- η[j,i] ----> u[j, i]   (i+1/2, j)
      (i, j)
```

- `η[j,i]` : 셀 중심 `(x_i, y_j)`, `x_i = (i+1/2)·dx`, `y_j = (j+1/2)·dy`
- `u[j,i]` : 동쪽 면 `(x_i + dx/2, y_j)`
- `v[j,i]` : 북쪽 면 `(x_i, y_j + dy/2)`

### 2.1 이산 연산자 (이중주기 경계, 인덱스는 mod로 순환)

| 기호 | 정의 | 결과 위치 |
|---|---|---|
| `Gx[η]` | `(η[j,i+1] − η[j,i]) / dx` | u-point |
| `Gy[η]` | `(η[j+1,i] − η[j,i]) / dy` | v-point |
| `D[u,v]` | `(u[j,i] − u[j,i−1])/dx + (v[j,i] − v[j−1,i])/dy` | η-point |
| `Ā_u[v]` | `¼ ( v[j,i] + v[j−1,i] + v[j,i+1] + v[j−1,i+1] )` | u-point |
| `Ā_v[u]` | `¼ ( u[j,i] + u[j,i−1] + u[j+1,i] + u[j+1,i−1] )` | v-point |
| `L[η]` | `D[ Gx[η], Gy[η] ]` = 표준 5점 라플라시안 | η-point |

**중요:** `L = D∘G` 로 **정의**한다. 5점 라플라시안을 따로 쓰지 않는다.
그래야 Helmholtz 연산자가 대칭 양정치이고 이산 에너지 항등식이 성립한다.

- 정확도: 모든 연산자 균일격자에서 **2차 중심차분**.
- `Ā` 평균은 코리올리 항 전용. 이류항은 Phase 1에서 추가.

### 2.2 이산 보존량 (진단용)

```
M(t) = Σ_ij η[j,i] · dx·dy                                     (질량)
E(t) = ½ Σ_ij [ H·(ū²+v̄²)|_center + g·η² ] · dx·dy             (에너지)
```
`ū² = ½(u[j,i]² + u[j,i−1]²)`, `v̄² = ½(v[j,i]² + v[j−1,i]²)`.
선형 무마찰계에서 `M`은 **기계정밀도 수준으로 보존**, `E`는 스킴에 따라 드리프트한다
(θ=0.5 → 무감쇠, θ>0.5 → 단조 감소). 이것이 V2의 핵심 판별식이다.

## 3. 시간 이산화

### 3.1 코리올리 항의 취급 (전 스킴 공통)

코리올리를 명시적으로 두면 시간 수렴차수가 1차로 떨어져 θ=0.5의 2차 검증이 불가능하다.
따라서 **θ_c-가중 Picard 반복**으로 통일한다:

```
반복 m = 0 .. n_picard−1 :
    v_cor^(m) = (1−θ_c)·Ā_u[v^n] + θ_c·Ā_u[v^(m)]       (m=0 이면 v^(0) := v^n)
    u_cor^(m) = (1−θ_c)·Ā_v[u^n] + θ_c·Ā_v[u^(m)]
    → 아래 §3.2/§3.3 의 한 스텝을 수행하여 (u^(m+1), v^(m+1), η^(m+1)) 획득
(u,v,η)^{n+1} := 마지막 반복 결과
```

- `n_picard = 1`, `θ_c = 0` → **명시적 코리올리** (1차, 저비용)
- `n_picard = 2`, `θ_c = 0.5` → **사다리꼴 코리올리** (2차) — **검증 기본값**
- 비용: Helmholtz 해를 `n_picard` 회 푼다. 이 자체가 축 F의 한 실험 대상이다.

### 3.2 스킴 A — 양해법 `fb` (forward–backward)

```
u^{n+1} = u^n + Δt ( f·v_cor − g·Gx[η^n] )
v^{n+1} = v^n + Δt ( −f·u_cor − g·Gy[η^n] )
η^{n+1} = η^n − Δt·H·D[u^{n+1}, v^{n+1}]        ← 갱신된 유속 사용 (backward)
```

**안정조건 (von Neumann, f=0):** `Δt ≤ 2 / ( c·sqrt(4/dx² + 4/dy²) )`,
정사각격자에서 `Δt_max = dx / (c·√2)`. 코리올리는 추가로 `f·Δt < 2` 를 요구한다.
> ⚠️ 순전한 forward Euler(연속식에 `u^n` 사용)는 **무조건 불안정**하다. 구현 금지.
> ⚠️ 3D 구현은 θ-스킴과 예측자 코드를 공유한다. `fb` 에서는 **θ = 0 으로 강제**한다 —
> 설정의 θ 를 그대로 읽으면 압력경사의 (1−θ) 만 남는다 (docs/90 N14, 2026-09-11).
> θ-스킴에서 θ→0 극한도 forward Euler이므로 **θ ∈ (0, 1] 만 허용**한다.

### 3.3 스킴 B — semi-음해법 `theta` (Casulli형)

압력경사항과 발산항을 θ-method로:

```
u^{n+1} = u^n + Δt·f·v_cor − g·Δt [ θ·Gx[η^{n+1}] + (1−θ)·Gx[η^n] ]
v^{n+1} = v^n − Δt·f·u_cor − g·Δt [ θ·Gy[η^{n+1}] + (1−θ)·Gy[η^n] ]
η^{n+1} = η^n − Δt·H [ θ·D[u^{n+1},v^{n+1}] + (1−θ)·D[u^n,v^n] ]
```

명시적 예측자를 정의:
```
Gu = u^n + Δt·f·v_cor − g·Δt·(1−θ)·Gx[η^n]
Gv = v^n − Δt·f·u_cor − g·Δt·(1−θ)·Gy[η^n]
```
그러면 `u^{n+1} = Gu − gΔtθ·Gx[η^{n+1}]`, `v^{n+1} = Gv − gΔtθ·Gy[η^{n+1}]` 이고,
연속식에 대입하면 **자유수면 Helmholtz 방정식**을 얻는다:

```
  ( I − g·H·θ²·Δt² · L ) η^{n+1}  =  R
  R = η^n − Δt·H·( (1−θ)·D[u^n,v^n] + θ·D[Gu,Gv] )
```

- `L` 은 음의 준정치 → 연산자 `A = I − gHθ²Δt²L` 은 **대칭 양정치(SPD)**, 항상 가역.
- 해를 얻은 뒤 `u^{n+1}, v^{n+1}` 를 위 식으로 **역산(back-substitute)** 한다.
- **`θ = 1` 이 완전음해법**이다. 별도 스킴을 만들지 않는다.
- 수렴차수 예측: `θ = 0.5` → 시간 2차, 무감쇠 / `θ ≠ 0.5` → 시간 1차, 감쇠율 `O((θ−½)Δt)`.
- 중력파에 대해 **θ ≥ 0.5 에서 무조건 안정**. 실질 제약은 코리올리(`fΔt<2`)와 정확도뿐.

### 3.4 스킴 C — `split_explicit` (Phase 1)

순압 모드를 `n_split` 개의 부분스텝으로 세분하여 양해적으로 적분하고 평균 back-coupling.
상세는 v0.2에서 정의한다. (현 문서 범위 밖 — 구현 금지)

## 4. Helmholtz 해법 (축 B)

### 4.1 `fft` — 이중주기 전용, 기계정밀도 정확
이산 라플라시안 `L` 의 고유값 (파수 `m=0..nx−1`, `n=0..ny−1`):
```
λ(m,n) = 2(cos(2πm/nx) − 1)/dx² + 2(cos(2πn/ny) − 1)/dy²   ≤ 0
```
따라서 `η̂ = R̂ / (1 − gHθ²Δt²·λ)`. 분모 ≥ 1 이므로 무조건 안정적으로 가역.
**검증(V1/V2)의 기본 해법** — 반복해 수렴오차가 시간이산화 오차에 섞이지 않게 한다.

### 4.2 `pcg_jacobi` — 일반 경계, 행렬 없는(matrix-free) PCG
- 전처리자 대각: `diag(A) = 1 + gHθ²Δt²·(2/dx² + 2/dy²)`
- 수렴 판정: `||r||₂ / ||b||₂ < rtol` (기본 `1e-12`), `max_iter` 도달 시 **경고 후 실패 처리**
- **PCG 반복당 전역 reduction 2회** — 이것이 RQ2에서 GPU 확장성의 병목이다.
  반복 횟수를 metrics에 **반드시 기록**한다.

### 4.3 결정성 (R7)
GPU reduction은 결정적이지 않을 수 있다. `pcg` 사용 시 백엔드 간 비교 허용오차는
`rtol` 의 10배까지 완화하고, 그 사실을 manifest에 기록한다.

## 5. 검증 케이스 해석해

### V1. 관성중력파 (inertia–gravity wave) — 이중주기

파수 `k = 2π m / Lx`, `l = 2π n / Ly`, `κ² = k² + l²`,
**분산관계** `ω = sqrt( f² + gH·κ² )`, 위상 `θ_p = kx + ly − ωt`:

```
η(x,y,t) = η₀ · cos(θ_p)
u(x,y,t) = η₀ /(H κ²) · [  ω k cos(θ_p) − f l sin(θ_p) ]
v(x,y,t) = η₀ /(H κ²) · [  ω l cos(θ_p) + f k sin(θ_p) ]
```

(선형 연속식·운동량식을 정확히 만족함을 대입으로 확인 가능.)
초기화는 각 변수를 **그 변수의 격자점 좌표**에서 평가한다(C-grid staggering 준수).

- 측정: `L2_rel`, `order_p`(격자 세분), `amp_ratio`, `phase_err`
- 참고: 이산 C-grid의 분산관계는 연속식과 다르므로 **고정 dt에서 dx→0 시켜야** 공간차수가 보이고,
  **고정 dx에서 dt→0** 시켜야 시간차수가 보인다. 두 스윕을 분리해서 수행한다.

### V2. 지형류 평형 (geostrophic balance) — 이중주기, **이산적으로 정확한 정상해**

연속방정식의 해석적 지형류 평형을 격자에 샘플링하면 이산 연산자에 대해 `O(dx²)` 만큼 불평형이라
정상해가 아니다. 대신 **이산 연산자의 정상 상태를 푸리에 공간에서 직접 구성**한다.

단일 모드 `(m, n)`, 격자 위상 `tx = 2πm/nx`, `ty = 2πn/ny` 에 대해
모든 필드를 `a[j,i] = Re[ â · exp(i(tx·i + ty·j)) ]` 로 둔다.
(모든 연산자가 실수 계수의 인덱스 시프트이므로 `Re[·]` 와 교환된다.)

이산 연산자의 심볼:
```
Gx  -> (e^{i·tx} − 1)/dx          A_u -> ¼(1 + e^{−i·ty})(1 + e^{i·tx})
Gy  -> (e^{i·ty} − 1)/dy          A_v -> ¼(1 + e^{−i·tx})(1 + e^{i·ty})
```
정상 운동량방정식 `f·A_u[v] = g·Gx[η]`, `f·A_v[u] = −g·Gy[η]` 을 풀면:
```
v̂ =  (4g/f) · (e^{i·tx} − 1) · η̂ / ( dx · (1 + e^{−i·ty}) · (1 + e^{i·tx}) )
û = −(4g/f) · (e^{i·ty} − 1) · η̂ / ( dy · (1 + e^{−i·tx}) · (1 + e^{i·ty}) )
```
`(1−e^{−iθ})/(1+e^{−iθ}) = i·tan(θ/2)` 를 쓰면 이 상태가 **이산 발산도 정확히 0** 임을 보일 수 있다:
```
D[u,v] -> (4g/f)/(dx·dy) · [ tan(tx/2)·tan(ty/2) − tan(ty/2)·tan(tx/2) ] = 0
```

따라서 **모든 t에서 정확해 = 초기장**이며, 관측되는 변화는 100% 수치 오차다.

- 제약: `m ≠ nx/2`, `n ≠ ny/2` (나이키스트에서 `1+e^{iθ}=0` → 평균 연산자 특이).
- 구현은 초기화 시 세 정상방정식의 잔차를 검사하고 `> 1e-10` 이면 예외를 던진다
  (`libs/core/cases.py::GeostrophicBalance._assert_balanced`) — 스펙과 코드의 불일치 조기 검출.
- 측정: `L2_rel(t)`, `mass_drift`, `energy_drift`.
  **질량 드리프트는 `M0` 가 아니라 `rms(η)·도메인면적` 으로 정규화한다** —
  두 검증 케이스 모두 공간평균이 0이라 `M0 ≈ 0` 이고, `M0` 로 나누면 무의미한 값이 나온다.

## 6. 백엔드가 반드시 재현해야 하는 것

1. **연산 순서까지 동일** — 부동소수 결합법칙이 성립하지 않으므로,
   `Gu` 계산 시 항의 덧셈 순서를 §3.3 표기 순서대로 유지한다.
2. `fft` 해법은 백엔드마다 라이브러리가 다르므로 fp64에서 `1e-12` 허용.
3. 진단량(`M`, `E`)의 합산은 **동일한 순회 순서**로 (또는 Kahan 합산으로) 계산한다.
4. 경계 처리(주기)는 halo 교환이 아니라 **인덱스 wrap** 으로 통일한다 (Phase 0).

## 7. Phase 2 (spec v0.2) — 3D 정역학 선형 Boussinesq

### 7.1 지배방정식

평평한 바닥, z-level 균일 `dz = H/nz`, 일정 `N²`, Boussinesq 부력 `b = -g rho'/rho0`:

```
du/dt - f v = -g d(eta)/dx + d(Phi')/dx + d/dz( nu du/dz )
dv/dt + f u = -g d(eta)/dy + d(Phi')/dy + d/dz( nu dv/dz )
Phi(z)      = int_z^0 b dz'                        (정역학, 부력 위치에너지)
Phi'        = Phi - <Phi>_z                        (연직평균 제거 - S7.2)
db/dt + w N^2 = d/dz( kappa db/dz )
w(z)        = -int_{-H}^{z} ( du/dx + dv/dy ) dz'  (바닥에서 w=0)
d(eta)/dt + d/dx int u dz + d/dy int v dz = 0
```

### 7.2 왜 `Phi` 에서 연직평균을 빼는가

`Phi` 의 연직평균은 z에 무관한 가속을 만들어 **순압 모드를 강제**한다.
이를 `eta` 로 흡수하는 것은 `eta -> eta - <Phi>/g` 라는 **변수 재정의**일 뿐이며,
모드분리(mode-splitting) 해양모델의 표준 관행이다.

> 이 처리가 없으면 §7.6의 내부파 해가 **정확해가 아니게 된다.**
> 연직평균을 제거하면 경압 강제가 심층적분 운동량에 기여하지 않으므로
> `int u dz = 0` 과 `eta = 0` 이 정확히 유지되고, 내부 모드가 닫힌다.

### 7.3 연직 격자와 이산 연산자

`k = 0` 이 표면, `k = 0..nz-1`. 층 중심 `z_k = -(k+1/2) dz`, 계면 `k`는 `z = -k dz`.
바닥까지의 높이 `zt = z + H`: 층 중심 `zt_k = (nz - k - 1/2) dz`, 계면 `zt_k = (nz - k) dz`.

| 기호 | 정의 | 위치 |
|---|---|---|
| `Dz[a]` | `( a[k-1] - 2 a[k] + a[k+1] ) / dz^2` (내부) | 층 중심 |
| `Wint[u,v]` | `w[k] = -dz * sum_{k'=k}^{nz-1} D[u,v][k']` | 계면 (`w[nz] = 0`) |
| `Wc[w]` | `0.5 ( w[k] + w[k+1] )` | 층 중심 |
| `Phi[b]` | `dz * ( 0.5 b[k] + sum_{k'<k} b[k'] )` | 층 중심 |
| `<a>_z` | `(1/nz) sum_k a[k]` | 2D |

경계조건: 표면 계면에서 `nu du/dz = tau_x/rho0`, 바닥 계면에서 `nu du/dz = r * u[nz-1]`.
`tau = 0`, `r = 0` 이면 양쪽 무플럭스.

### 7.4 연직 음해 확산 — 배치 삼중대각

`alpha[k] = theta_v * dt * nu[k] / dz^2`, 행렬 `A = I - theta_v dt Dz`:

```
k = 0      :  (1 + alpha_b) a[0] - alpha_b a[1]                       = rhs[0] + theta_v dt tau/(rho0 dz)
0 < k < nz-1: -alpha_t a[k-1] + (1 + alpha_t + alpha_b) a[k] - alpha_b a[k+1] = rhs[k]
k = nz-1   : -alpha_t a[nz-2] + (1 + alpha_t + theta_v dt r/dz) a[nz-1]       = rhs[nz-1]
```
`alpha_t`, `alpha_b` 는 각각 위/아래 계면의 `nu` 로 만든 계수다.

> **`nx*ny = 10,000` 개의 독립 삼중대각계, 각 크기 `nz = 30`.**
> 계수는 전 열이 동일한 경우에도 **전체 3D 배열로 다룬다** —
> 열마다 다른 실제 난류 폐합 상황의 연산량·메모리 트래픽을 재현해야
> GPU 벤치마크가 정직해지기 때문이다 (한 번만 분해하면 비용을 과소평가한다).

### 7.5 시간적분 — Casulli 3D

1. 명시적 예측자 (층별):
   `Gu[k] = u[k] + dt f v_cor[k] + dt dPhi'/dx[k] - g dt (1-theta) dx(eta^n) + (1-theta_v) dt Dz(u^n)[k]`
2. **삼중대각 1**: `A gh = Gu` → `gh` (연직 점성 적용)
3. **삼중대각 2**: `A q = 1` → `q` ("유효 깊이 프로파일")
4. **Helmholtz**: `Hh = dz * sum_k q[k]` 로
   `eta^{n+1} - g theta^2 dt^2 L_Hh[eta^{n+1}] = eta^n - dt[ (1-theta) D(U^n) + theta D(dz sum_k gh) ]`
5. **역산**: `u^{n+1}[k] = gh[k] - g dt theta q[k] dx(eta^{n+1})`
6. `w` 를 `u^{n+1}` 로부터 진단, `b` 를 `A_b b^{n+1} = b^n - dt Wc[w] N^2 + (1-theta_v) dt Dz_b(b^n)` 로 갱신

`nu = 0`, `b = 0` 이면 `q[k] = 1`, `Hh = H` 가 되어 **§3.3 의 2D 알고리즘으로 정확히 환원된다.**

### 7.6 3D 검증 케이스

| # | 케이스 | 해석해 | 무엇을 검증하나 |
|---|---|---|---|
| **V3D-1** | `barotropic3d` | ✅ **기계정밀도** | `nu=0, b=0` 에서 2D 결과와 완전 일치. 자유표면/Casulli 경로 전체 |
| **V3D-2** | `vdiffusion` | ✅ **공간 정확** | `u[k] = cos(m zt_k) exp(nu lam t)`, `lam = (2cos(n pi/nz) - 2)/dz^2` (이산 고유값). 공간오차 0이므로 **시간차수만** 측정 |
| **V3D-3** | `baroclinic_igw` | ✅ 연속해 | 연직 모드 `n`, `m = n pi / H`, `c_n = N/m`, `omega = sqrt(f^2 + c_n^2 kappa^2)` |

**V3D-3 정확해** (`zt = z + H`, `theta_p = k x + l y - omega t`):
```
u = (g eta0 / (c_n^2 kappa^2)) [ omega k cos(theta_p) - f l sin(theta_p) ] cos(m zt)
v = (g eta0 / (c_n^2 kappa^2)) [ omega l cos(theta_p) + f k sin(theta_p) ] cos(m zt)
b = -g eta0 m cos(theta_p) sin(m zt)
w =  (g eta0 omega / (c_n^2 m)) sin(theta_p) sin(m zt)
eta = 0
```
즉 **2D 관성중력파 해에서 `gH -> c_n^2` 로 바꾸고 `cos(m zt)` 를 곱한 것**이다.
`m H = n pi` 이므로 `w` 가 바닥과 표면에서 모두 0이고 `int u dz = 0` 이라 `eta = 0` 이 유지된다.

## 8. spec v0.3 — split-explicit 순압 모드 분리 (3D)

### 8.1 왜 이 스킴이 필요한가

`docs/21` §3에서 semi-음해법의 비용이 **전역 reduction을 동반한 PCG 반복**에 지배되고,
GPU에서 반복당 CPU의 1.7~9.6배가 든다는 것이 측정되었다.
split-explicit은 같은 목표(빠른 표면중력파를 경압 시간스텝에서 분리)를
**타원형 해 없이** 달성한다 — 순압 모드를 작은 부분스텝으로 **양해적으로** 적분한다.

> **전역 reduction이 0회다.** 순압 부분스텝은 전부 국소 stencil 연산이다.
> 이것이 문헌 L3의 "semi-음해 vs split-explicit" 논쟁에 빠져 있던 하드웨어 축이다.

### 8.2 방정식 분리

심층적분 수송 `U = ∫u dz`, `V = ∫v dz`. 순압계(선형, 평평한 바닥):

```
dU/dt - f V = -g H d(eta)/dx + Fx
dV/dt + f U = -g H d(eta)/dy + Fy
d(eta)/dt + dU/dx + dV/dy = 0
```

`Fx`, `Fy` 는 3D 운동량에서 온 **경압 강제의 심층적분**이며,
**코리올리는 제외한다** — 순압계가 자기 코리올리를 따로 가지므로 중복 계산이 된다.

### 8.3 한 스텝의 절차

1. 경압 예측자 (**순압 압력경사 `-g grad(eta)` 를 뺀 채**):
   `Gu = u + dt (f v_cor + dPhi'/dx) + (1-theta_v) dt Dz(u)`
2. **삼중대각**: `A gh_u = Gu` (연직 점성은 여전히 음해 — §7.4 그대로)
3. 순압 강제에서 코리올리를 제거:
   `Fx = ( dz*sum(gh_u) - dz*sum(u) ) / dt - dz*sum(f v_cor)`
   > **가변 수심(§10) 에서의 정의 (2026-09-11, docs/90 N15).** 제거하는 코리올리는 4단계의
   > 순압계가 **자기가 더하는 것과 같은 연산자**로 계산한다:
   > `Fx = ( sum(dz3u gh_u) - U0 ) / dt - f [ (1-tc) A_u[V0] + tc A_u[sum(dz3v gh_v)] ]`,
   > `A_u` 는 2D 면마스크 평균, `U0 = sum(dz3u u)`. 평평한 바닥에서는 위 식과 정확히 같다
   > (평균이 균일 dz 와 교환). 지형 위에서는 `sum(dz3u A_u^3D[v])` 와 `A_u[sum(dz3v v)]` 가
   > O(1) 로 다르므로, 3D 연산자로 빼고 2D 연산자로 더하면 두 모드의 코리올리가 상쇄되지
   > 않고 dt→0 에서도 사라지지 않는 구조적 오차가 남는다 (실측: 닫힌 해산 분지에서 fb 대비
   > u 오차 100 %).
4. **순압 부분스텝** `M = n_split` 회, `ddt = dt / M`, forward-backward.
   코리올리는 §3.1의 `theta_cor` 가중 Picard 반복을 그대로 쓴다:
   ```
   반복 m = 1..n_picard :
      v_cor = (1-tc) A_u[V^s] + tc A_u[V^(m)]
      u_cor = (1-tc) A_v[U^s] + tc A_v[U^(m)]
      U^(m+1) = U^s + ddt ( f v_cor - g H Gx[eta] + Fx )
      V^(m+1) = V^s + ddt ( -f u_cor - g H Gy[eta] + Fy )
   eta <- eta - ddt D[U, V]
   ```
   > **순차식 코리올리를 쓰면 안 된다.** 부분스텝 안에서 갱신된 `U` 로 `V` 의 코리올리를
   > 계산하는 단순한 forward-backward는 **1차 정확도**이고, 그것이 스킴 전체의 차수를
   > 1로 끌어내린다 (실측: 2.10 -> 1.10).
5. **경압 보정** — 3D 유속의 연직평균을 순압 결과로 교체:
   `u^{n+1}[k] = gh_u[k] - <gh_u>_z + U / H`
   이로써 `int u^{n+1} dz = U` 가 정확히 성립한다.
6. `w`, `b` 는 §7.5 6단계와 동일.

### 8.4 안정조건과 `n_split`

순압 부분스텝은 표면중력파 CFL을 지켜야 한다:
`ddt <= 2 / ( c sqrt(4/dx^2 + 4/dy^2) )` (§3.2와 동일).
`n_split = 0` 이면 자동 선택: `n_split = ceil( 1.2 * dt / ddt_max )`.
경압 스텝 `dt` 는 내부파 속도 `c_n = N/m` 로 제한되므로 `c` 보다 훨씬 큰 값을 쓸 수 있다.

### 8.5 평균화 필터를 쓰지 않는다 — 의도된 단순화

실제 모델(ROMS, Shchepetkin & McWilliams 2005)은 부분스텝 결과에 **평균화 필터**를 걸어
모드 분리로 생기는 불일치를 억제한다. spec v0.3은 **마지막 부분스텝 값을 그대로** 쓴다
(`barotropic_average = 'none'`).

> 이유: 시간평균값은 `t+dt` 에서의 값이 아니므로 **정확해로 수렴하지 않는다** —
> V3D-1이 검증 케이스로 성립하지 않게 된다. 필터 없는 분리는 장시간 적분에서
> 약한 불안정을 보일 수 있으므로, `barotropic_average = 'mean'` 을 설정 축으로 남겨
> **그 대가를 측정 가능하게** 해 둔다.

### 8.6 검증 케이스에서의 거동 (예측)

| 케이스 | split-explicit이 하는 일 | 기대 |
|---|---|---|
| `barotropic3d` | `F = 0` 이므로 순압계가 곧 2D 선형 천수계. 경압 보정은 `u = U/H` | **§3.2 forward-backward와 동등**, 2차 수렴 (부분스텝 기준) |
| `baroclinic_igw` | `Phi'` 의 연직평균이 0이므로 `F = 0`, `eta = 0`, `int u dz = 0` 이 유지되어 순압 모드가 정지 | 내부 모드만 양해 적분 → 2차 수렴 |
| `vdiffusion` | 수평 운동 없음 → 순압계 정지 | 연직 삼중대각만 작동 |

세 케이스 모두 **§7.6의 해석해가 그대로 유효**하다.

## 9. spec v0.4 — 완전한 코어 (비선형 이류 · T/S · 상태방정식 · 기상 경계)

spec v0.2/v0.3은 **선형** 계였다. v0.4는 실제 해양모델 코어가 갖는 항들을 채운다.

### 9.1 지배방정식

```
du/dt + ADV(u) - f v = -g d(eta)/dx + d(Phi')/dx + d/dz( nu du/dz ) + Ah lap_h(u)
dv/dt + ADV(v) + f u = -g d(eta)/dy + d(Phi')/dy + d/dz( nu dv/dz ) + Ah lap_h(v)
dC/dt + DIV(u C)     = d/dz( kappa dC/dz ) + Kh lap_h(C)          C in {T, S}
b                    = g ( alphaT (T - T0) - betaS (S - S0) )      (선형 상태방정식)
Phi(z)               = int_z^0 b dz' ,  Phi' = Phi - <Phi>_z
w(z)                 = -int_{-H}^{z} ( du/dx + dv/dy ) dz'
d(eta)/dt + d/dx int u dz + d/dy int v dz = 0
```

`tracers = 'buoyancy'` 이면 `b` 를 직접 예후변수로 쓰고 상태방정식을 건너뛴다
(v0.2/v0.3의 검증 케이스가 그대로 유효하도록 남긴 경로).
`tracers = 'TS'` 이면 `T`, `S` 가 예후변수이고 `b` 는 진단량이다.

### 9.2 이류 — 플럭스형, Arakawa C-grid

`advection = 'none' | 'centered2' | 'upwind1'` (축 C).
**`'none'` 이 기본값이다** — §7.6의 선형 해석해들이 이류항이 있으면 더 이상 정확해가 아니기 때문이다.

**추적자** (셀 중심): 동쪽 면의 플럭스 `Fx[i] = u[i] * Cface[i]`
```
centered2 : Cface[i] = 0.5 ( C[i] + C[i+1] )
upwind1   : Cface[i] = C[i]   if u[i] > 0  else  C[i+1]
```
연직 계면 플럭스 `Fz[k] = w[k] * Cface_z[k]`, 계면 `k` 는 층 `k-1`(위)과 `k`(아래) 사이.
```
DIV(uC)[i,j,k] = (Fx[i]-Fx[i-1])/dx + (Fy[j]-Fy[j-1])/dy + (Fz[k]-Fz[k+1])/dz
```

**운동량** (u-점, 2차 중심 플럭스형):
```
d(uu)/dx |_(i+1/2) = ( ubar[i+1]^2 - ubar[i]^2 ) / dx ,  ubar[i] = 0.5(u[i-1]+u[i])
d(vu)/dy |_(i+1/2) = ( vbar[j] ubar_y[j] - vbar[j-1] ubar_y[j-1] ) / dy
                      vbar[j] = 0.5( v[i,j] + v[i+1,j] ) ,  ubar_y[j] = 0.5( u[j] + u[j+1] )
d(wu)/dz |_(i+1/2) = ( wbar ubar_z |_top - wbar ubar_z |_bot ) / dz
                      wbar = 0.5( w[i] + w[i+1] ) ,  ubar_z[k] = 0.5( u[k-1] + u[k] )
```
`v` 는 대칭적으로 정의한다.

### 9.3 수평 점성·확산

`lap_h(a) = ( a[i+1] - 2a[i] + a[i-1] )/dx^2 + ( a[j+1] - 2a[j] + a[j-1] )/dy^2`,
계수 `Ah` (운동량), `Kh` (추적자).

**젖은/마른 경계에서의 정의 (2026-09-14 명문화).** 위 5점 스텐실은 내부에서의 형태이고,
해안에서는 `L = D∘G` 규칙(§4)을 그대로 따른다 — 기울기는 **면 마스크**로, 발산은 **그 장이
사는 점의 마스크**로 막는다.

| 대상 | `gradx` 마스크 | `grady` 마스크 | `div` 마스크 |
|---|---|---|---|
| `u` (u-점) | `mask3u` | `mask3v` | `mask3u` |
| `v` (v-점) | `mask3u` | `mask3v` | `mask3v` |
| 추적자 (셀 중심) | `mask3u` | `mask3v` | `mask3` |

내부(모든 마스크 = 1)에서는 위 5점 식과 **정확히 같고**, 차이는 해안 한 줄에만 나타난다.
`u`·`v` 의 교차미분이 엄밀히는 코너·셀중심에 사는 것을 면 마스크로 근사한 것이며, 다섯 구현이
**모두 같은 선택**을 하므로 R2 게이트(1e-16)는 유지된다. 코너 마스크로 바꾸려면 스펙을 먼저
고친다(R1). 미문서화 상태로 발견된 경위는 docs/90 N34.

**양해적으로** 처리하므로
`dt < dx^2 / (4 Ah)` 를 지켜야 한다 (연직 확산과 달리 음해로 만들지 않는다 — 수평 방향은
격자가 크므로 제약이 훨씬 느슨하다).

### 9.4 기상 경계 (surface forcing)

| 항목 | 표면 계면 조건 | 설정 키 |
|---|---|---|
| 바람 응력 | `nu du/dz = tau_x / rho0`, `nu dv/dz = tau_y / rho0` | `tau_x`, `tau_y` |
| 열 플럭스 | `kappa dT/dz = Q / (rho0 cp)` | `q_heat` [W m-2], `cp` |
| 담수 플럭스 | `kappa dS/dz = S0 (E-P) / rho0` (가상 염 플럭스) | `q_salt` |
| 바닥 | `nu du/dz = r u[nz]` (선형 마찰) | `bottom_drag` |

응력·플럭스는 이미 §7.4의 삼중대각 우변에 `theta_v` 가중으로 들어간다.

### 9.5 새 검증 케이스

| # | 케이스 | 해석해 | 무엇을 검증하나 |
|---|---|---|---|
| **V3D-4** | `tracer_advect` | ✅ 정확 | 균일 유속 `(u0,v0)` 로 추적자 정현파를 평행이동. 유속이 균일하므로 운동량 이류가 0이고 발산이 0이라 `eta` 도 정지 → **이류 연산자만** 분리 검증 |
| **V3D-5** | `ekman` | ✅ 정상해 | 바람 응력 + 연직 점성 + 코리올리의 **정상 Ekman 나선**. 유한 수심 자유슬립 바닥 |

**V3D-4 정확해:** `C(x,y,t) = cos( k(x - u0 t) + l(y - v0 t) )`, `u = u0`, `v = v0`, `eta = 0`, `b = 0`.
균일 유속은 이류 자기 자신을 만들지 않으므로 운동량은 정지 상태를 유지한다.

**V3D-5 정확해** (복소 표기 `W = u + i v`, `zt = z + H`, `a = (1+i)/D`, `D = sqrt(2 nu / f)`):
```
W(z) = tau / ( rho0 nu a sinh(a H) ) * cosh( a * zt )
```
표면에서 유속은 바람의 오른쪽 45도 (`f > 0`), 심층으로 갈수록 나선을 그리며 감쇠한다.
이산 연산자의 정확해는 아니므로 **`nz` 세분에서 2차 수렴**을 측정한다.

> **주의:** `advection` 이 `'none'` 이 아니면 §7.6의 V3D-1~3은 더 이상 정확해를 갖지 않는다.
> 회귀 검증은 항상 `advection='none'` 으로 돌린다.

## 10. spec v0.5 — 실지형 · 연직좌표 · 실경계 · 비선형 상태방정식

### 10.1 왜 이 절이 필요한가 (동기)

v0.1–v0.4 의 코어는 다음 네 가지를 **평평하게** 가정한다.

| 가정 | v0.4 까지 | 실제 해양모델 (NEMO/ROMS/SCHISM/Delft3D) |
|---|---|---|
| 바닥 | 평탄 `H = const` | `H(x,y)` 해저지형, 육지 마스크 |
| 연직좌표 | z-level, `dz = H/nz` 균일 | z-level+부분셀 / z\* / σ / 하이브리드 |
| 수평경계 | 이중주기 | 닫힌 벽 + 개방(방사) 경계 |
| 상태방정식 | 선형 `b = g(alpha T - beta S)` | TEOS-10 / EOS-80 비선형 |

이 네 가지는 "장난감 모델"이라는 비판의 실체이자, 동시에 **이 연구의 핵심 측정량을
바꾸는 요인**이다. 특히:

> **평탄 바닥에서 자유표면 Helmholtz 연산자는 상수계수다.** 그래서 FFT 가 정확해를 주고,
> PCG 반복수는 격자에만 의존한다. 실제 지형에서는 연산자가 `∇·(H ∇η)` 형태의 **변계수**가
> 되고, 조건수는 `H_max/H_min` 과 지형 거칠기에 지배된다. 즉 **docs/21 이 측정한 GPU↔CPU
> 교차점(208 반복/스텝)은 지형의 함수**다. 이것이 선행연구(L13)에 없는 축이다.

따라서 v0.5 는 물리를 채우는 작업인 동시에 **축 H (지형 거칠기)** 를 실험행렬에 추가하는
작업이다.

### 10.2 지형과 마스크

해저지형은 `eta` 점에 정의한다: `H[j,i] > 0` (양수, 아래방향). 육지는 `mask[j,i] = 0`.

면(face) 깊이 규약은 `domain.face_rule` 로 고른다. 기본은 **최솟값**이며, 이것이
NEMO `ln_zco` 계열·ROMS 의 관행이다.

| `face_rule` | 정의 | 절단오차 차수 (V5-2 실측) |
|---|---|---|
| `min` (기본) | `Hu = min(H[i], H[i+1])` | **1.04** |
| `mean` | `Hu = (H[i] + H[i+1]) / 2` | **2.00** |
| `harmonic` | `Hu = 2 H[i] H[i+1] / (H[i]+H[i+1])` | **2.00** |

```
masku[j,i] = mask[j,i] * mask[j,i+1]
maskv[j,i] = mask[j,i] * mask[j+1,i]
```

평균이 아니라 최솟값을 쓰는 이유: 면을 통과하는 유량이 얕은 쪽 셀이 담을 수 있는 양을
넘지 않아야 이산 연속방정식이 양의 수심을 보존한다.

> **대가:** 그 안전성은 **자유표면 연산자의 차수 하나**를 값으로 치른다. 매끄러운 `H` 에
> 대해 `min` 은 1차, `mean`/`harmonic` 은 2차다. nx=1024 에서 오차 크기 차이는 **30배**
> (3.25e-4 vs 1.09e-5). 건조/습윤이나 급경사가 없는 영역에서는 2차 규약을 쓰는 편이
> 옳고, `min` 은 얕은 이웃과 접한 면에만 국한하는 것이 이상적이다 — v0.5 는 전역 선택만
> 제공하고 그 혼합은 구현하지 않았다.

**지형 케이스** (`config/domain.toml`, `bathymetry.kind`):

| kind | `H(x,y)` | 목적 |
|---|---|---|
| `flat` | `H0` | v0.4 로의 환원(V5-1) |
| `slope` | `H0 (1 - s * x/Lx)` | 대륙붕 경사, 단조 지형 |
| `seamount` | `H0 [1 - h_rel * exp(-(r/L)^2)]` | **Beckmann–Haidvogel(1993) 해산 시험** |
| `ridge` | `H0 [1 - h_rel * exp(-((x-x0)/L)^2)]` | 1차원 능선 |
| `rough` | 스펙트럼 합성, 거칠기 `r` 지정 | **축 H 스윕용** |

거칠기 지표는 두 가지를 함께 기록한다.
```
r_std  = std(H) / mean(H)                       (진폭 거칠기)
r_grad = max_faces( |H[i+1]-H[i]| / (H[i+1]+H[i]) )   (기울기 파라미터 rx0, Haney number)
```
`rx0` 는 σ 좌표계 압력경사 오차의 표준 지표이며 실무 한계값은 `rx0 <= 0.2` 이다.
`rough` 는 `r_std` 를 목표값으로 받아 스펙트럼 진폭을 이분법으로 맞춘다 (재현성: 고정 시드).

### 10.3 연직좌표 (`vcoord`)

기준 층두께 `dzr[k]` 는 `sum_k dzr[k] = H0` 를 만족하는 고정 표(기본 균일).
셀 `[k,j,i]` 의 실제 두께 `dz3[k,j,i]` 는:

| vcoord | `dz3[k,j,i]` | 성질 |
|---|---|---|
| `zlevel` | `clip(dzr[k], 0, 남은깊이)`, 마지막 젖은 셀은 **부분셀** | 층면이 수평 → 압력경사 오차 없음, 계단형 바닥 |
| `zstar` | `dz_zlevel[k,j,i] * (1 + eta/H)` | 층면 수평 + 자유표면 호흡, NEMO `ln_linssh=.false.` 와 동형 |
| `sigma` | `s[k] * (H + eta)`, `sum_k s[k] = 1` | 바닥추종, 계단 없음, **압력경사 오차 발생** |

부분셀 최소두께는 `min_partial * dzr[k]` (기본 0.1) 로 클립하고, 그보다 얕으면 그 셀을
마른 셀로 만든다. 젖은셀 마스크 `mask3[k,j,i]` 가 따라 나온다.

`zlevel` 은 `eta` 를 표층 두께에 넣지 않는다(**선형 자유표면**, v0.4 와 동일). 이것이
V5-1 환원시험이 성립하는 이유다.

### 10.4 마스킹된 이산 연산자

모든 수평 연산자는 **면 마스크를 곱해** 사용한다.
```
Gx[eta][j,i] = masku[j,i] * (eta[j,i+1] - eta[j,i]) / dx
D[U,V][j,i]  = ( U[j,i] - U[j,i-1] ) / dx + ( V[j,i] - V[j-1,i] ) / dy      (U,V 는 이미 마스킹됨)
```
`D` 와 `-G` 가 서로 **수반(adjoint)** 관계를 유지하므로 Helmholtz 연산자는 여전히 대칭
양정부호이고 PCG/다중격자가 그대로 적용된다. 벽에서 `masku = 0` 은 곧 법선유속 0
(자유슬립 닫힌 경계)이다.

**경계조건 (`bc_x`, `bc_y`)**

| 값 | 처리 |
|---|---|
| `periodic` | 인덱스 순환 (v0.1 그대로) |
| `closed` | 도메인 가장자리 면 마스크 0, 순환 없음 |
| `open` | **Flather 방사** — 순압 법선유속을 `U = U_ext + sqrt(g/Hb) (eta - eta_ext)` 로 강제 |

Flather 는 순압 모드에만 적용한다. 경압 모드는 가장자리 `n_relax` 셀에서 기준값으로
완화(sponge)한다: `phi <- phi + dt/tau(i) (phi_ext - phi)`, `tau` 는 안쪽으로 갈수록 증가.

### 10.5 자유표면 Helmholtz — 변계수

v0.2 §7.5 에서 상수였던 `h_eff` 가 이제 면마다 다르다.
```
Ku[j,i] = masku[j,i] * sum_k ( dz3u[k,j,i] * q[k,j,i] )      (u 면의 유효 수심)
Kv[j,i] = maskv[j,i] * sum_k ( dz3v[k,j,i] * q[k,j,i] )
```
`q` 는 §7.5 와 같이 `A q = 1` 의 해다. 그러면 풀어야 할 계는
```
eta[j,i] - g theta^2 dt^2 * D[ K G[eta] ][j,i] = rhs[j,i]
```
이고, 이는 대칭 양정부호이지만 **FFT 로 풀 수 없다**. 따라서:

| solver | v0.5 에서의 가용성 |
|---|---|
| `fft` | ❌ `flat` + `periodic` 일 때만 (그 외에는 즉시 오류) |
| `pcg_jacobi` | ✅ 대각 전처리 = `1 + g th^2 dt^2 (Ku+Ku_w)/dx^2 + ...` |
| `pcg_rbgs` | ✅ |
| `rbgs` | ✅ |
| `multigrid` | ✅ 단, 계수를 조립 평균(coarse-grid operator = 면계수 조화평균)으로 제한 |

> **측정 대상:** 반복수 `N_iter(r_std, r_grad, nx, cfl)`. 이 함수가 GPU↔CPU 교차점을
> 어디로 옮기는지가 RQ6 이다.

### 10.6 비선형 상태방정식 (축 E-EOS)

`physics3d_v05.eos` 는 세 수준을 갖는다. 셋 다 `b = -g (rho - rho0)/rho0` 를 돌려준다.

| eos | 식 | 대략 FLOP/셀 | 물리 |
|---|---|---|---|
| `linear` | `rho' = rho0(-alpha_T Ta + beta_S Sa)` | ~4 | v0.4 와 동일 |
| `seos` | Roquet et al. (2015) 단순화 EOS (아래) | ~15 | **캐블링 + 열압축성** 포함 |
| `teos10` | Roquet et al. (2015) polyTEOS10-bsq 55항 | ~70 | NEMO 4 기본과 동일 |

`seos` (NEMO `ln_seos`), `Ta = T - 10`, `Sa = S - 35`, `z` 는 깊이[m] (양수):
```
rho' = -a0 (1 + 0.5*lam1*Ta + mu1*z) * Ta
     +  b0 (1 - 0.5*lam2*Sa - mu2*z) * Sa
     -  nu_ts * Ta * Sa
a0=1.6550e-1, b0=7.6554e-1, lam1=5.9520e-2, lam2=7.4914e-4,
mu1=1.4970e-4, mu2=1.1090e-5, nu_ts=2.4341e-3
```
`lam1` 이 캐블링(열팽창계수의 온도 의존성), `mu1` 이 열압축성(압력 의존성)을 준다.

> **왜 성능 연구에서 EOS 가 중요한가:** 해양모델 커널은 거의 전부 메모리 대역폭 한계다
> (docs/13: fp64 ridge AI = 1.25 FLOP/byte). EOS 는 **유일하게 연산집약적인 커널**이다.
> `teos10` 은 3개 입력(T,S,z) 을 읽고 1개(rho)를 써서 ~70 FLOP → AI ≈ 70/32 ≈ 2.2 FLOP/byte
> 로 **ridge 위쪽**, 즉 연산한계다. 따라서 EOS 수준을 올리면 GPU 대 CPU 비가 **개선**되어야
> 한다. 이 예측을 측정하는 것이 RQ7 이다.

### 10.7 압력경사 (지형 위에서)

`sigma` 좌표에서는 `Phi` 의 수평미분이 등압면이 아니라 등σ면을 따라가므로 유명한
**압력경사 오차**가 생긴다. v0.5 는 표준 밀도-야코비안 형태를 쓴다:
```
PGx[k,j,i] = -( d/dx Phi |_sigma  -  (dz/dx)|_sigma * dPhi/dz )
```
두 항 모두 같은 σ면에서 계산하고 차분하므로 서로 상쇄되어야 하지만 이산적으로는 남는다.
이 잔차의 크기가 **V5-3 (해산 정지시험)** 의 측정량이다.
`zlevel`/`zstar` 에서는 두 번째 항이 0 이므로 오차가 원리적으로 없다.

깊이평균 제거(§7.2)는 그대로 유지하되, 이제 **각 컬럼의 실제 수심으로 가중**한다:
```
Phi' = Phi - ( sum_k dz3[k] Phi[k] ) / ( sum_k dz3[k] )
```

**V5-2 정의.** 해석적이고 주기적인 두 함수
```
H(x,y)   = H0 ( 1 + a sin(2 pi x/L) sin(2 pi y/L) ),   a = 0.3
eta(x,y) = cos(2 pi m x/L) cos(2 pi n y/L),            m = 2, n = 1
```
에 대해 `∇·(H∇η)` 는 닫힌 형태로 미분된다. 이산 연산자를 적용해 그 정확값과 비교하고
nx = 64 … 1024 에서 차수를 측정한다.

**게이트는 2차 규약(`mean`, `harmonic`)에만 건다** — 그것이 연산자 구현 자체를 검증한다.
`min` 의 차수는 게이트가 아니라 **측정 결과**다(1.04). 전체 제조해법(시간항·코리올리 포함)은
스테퍼에 source 훅이 필요하며 v0.5 에서는 구현하지 않았다.

**V5-3 판정 기준.** 문헌 관행에 따라 `max|u|` [cm/s] 를 보고한다. `zlevel` 은 반올림
수준(<1e-10 m/s), `sigma` 는 `rx0` 에 대해 단조 증가해야 한다.

## 11. spec v0.6 — 연직 난류 폐쇄 · 고차 이류 (대표 코어의 완성)

### 11.1 왜 이 절이 필요한가

v0.5 까지는 정역학 원시방정식의 **dynamical core** 다. 실제 해양모델의 스텝 비용에서 큰 몫을
차지하는 두 연산이 빠져 있고, 둘은 GPU 에서 정반대 성격을 갖는다:

- **연직 난류 폐쇄** — 열(column) 단위의 국소 비선형 대수 + 삼중대각 하나 더. EOS 와 같은
  "GPU 가 잘하는" 부류. 그러나 연직 확산계수가 매 스텝 3D 배열이 되므로 §7.4 의 삼중대각 계수와
  §10.5 의 Helmholtz 계수(`q = A⁻¹1`, `K = Σ dz q`)를 **매 스텝 다시 만든다** — 이 비용이 실제 모델의
  비용이다.
- **고차 이류** — 넓은 스텐실(5점) + 제한자의 분기. 메모리 대역폭과 분기 비용이 지배하고,
  CPU/GPU 격차가 좁아지는 부류.

둘을 넣지 않은 벤치는 "어떤 연산을 뺐기 때문에" GPU 가 유리해 보일 수 있다. v0.6 은 그 의심을 없앤다.

### 11.2 1-방정식 TKE 폐쇄 (`closure = 'tke'`)

Gaspar et al. (1990) 계열 (NEMO `zdftke` 의 골격). 난류운동에너지 `e` 는 **계면**(§7.3 의 `w` 위치,
k = 0 … nz)에 정의한다.

```
de/dt = K_m S²  −  K_h N²  −  ε  +  ∂z( K_e ∂z e )
S² = (∂z u)² + (∂z v)²  (u,v 는 계면 위·아래 층 중심값의 차분; u,v 는 면 값이므로 먼저 셀 중심으로 평균)
N² = ∂z b                (b = 부력, TS 모드에서는 EOS 로 진단한 b)
ε  = c_ε e^{3/2} / l_ε
K_m = c_k l_k sqrt(e) + ν_b ,   K_h = K_m / Pr_t + κ_b ,   K_e = K_m
```

**혼합길이** (Gaspar 1990 의 적분 길이; 결정적, 열 단위):
```
l_up(k) : 계면 k 에서 위로, 운동에너지 e(k) 가 성층을 거슬러 갈 수 있는 거리 —
          ∫_0^{l_up} N²(z_k − s) s ds = e(k)   (균일 N 이면 l = sqrt(2e)/N)
l_dn(k) : 같은 정의로 아래로.  둘 다 표면/바닥까지의 거리(+z_0)로 상한.
이산화: 계면 k 에서 한 계면씩 멀어지며, 계면 k∓j 를 건너는 비용 N²_j·dzi_j·(d + dzi_j/2)
        (d = 지금까지 간 거리)를 예산 e(k) 에서 차감, 예산이 바닥나는 마지막 걸음은 잘라 쓴다.
l_k = max(l_min, sqrt(l_up l_dn)) ,   l_ε = max(l_min, min(l_up, l_dn))
```
> 처음 구현은 예산을 `∫N² dz ≤ e`(선형)로 잘못 두어 `l ∝ e` 가 되었고, `K ∝ e^{3/2}` 의
> 초선형 되먹임으로 혼합층이 13 h 만에 폭주해 50 m 를 한 시간에 섞었다. 위치에너지 형태
> (`∫N² s ds`)라야 `l ∝ sqrt(e)` 로 되먹임이 선형이다.

**혼합길이 축 `mxl`** (`integral` | `recursive`). 위 식은 `integral` 이며 **열당 O(nz²)**
연산이다(계면마다 최대 nz 계면을 훑는다). 실모델(NEMO `nn_mxl=2`, Blanke & Delecluse 1993)이 쓰는
근사는 부력길이를 두 번의 **O(nz)** 스윕으로 제한한다:
```
l(k)   = sqrt( 2 e(k) / max(N²(k), N²_min) )              부력길이
l(k)  <- min( l(k), z_s(k) + z_0, z_b(k) + z_0 )          벽까지의 거리
아래로: k = 1 … nz  :  l(k) <- min( l(k), l(k-1) + dzi(k) )   ("물리적 제한")
위로  : k = nz … 1  :  l(k) <- min( l(k), l(k+1) + dzi(k+1) )
l_up = l_dn = l  →  l_k = l_ε = max(l_min, l)
```
같은 물리를 **산술 15배 적게**(nz=30) 구현하는 대안이며, 답은 같지 않다(제한자가 다르다).
따라서 두 형태는 **하나의 축**이고 둘 다 V6-3 로 검증한다. 이 축은 커널 프로파일에서 폐쇄가
스텝의 최대 커널(H100 1000²×30 에서 21.8 %)이라는 측정에서 나왔다 — docs/35.

**시간적분** (한 스텝의 **처음**, 현재 u·v·b 로 e^{n+1} 과 K 를 만들고 그 K 로 이 스텝을 푼다):**시간적분** (한 스텝, 층 예단 뒤 · 추적자 예단 앞):
1. 생성항 `P = K_m S² − K_h N²` 는 **현재** `K`·속도·부력으로 양해.
2. 소산은 **선형화 음해**: `ε ≈ (c_ε sqrt(e^n) / l) · e^{n+1}`.
3. 연직 확산은 음해(θ_v = 1, 완전 음해) — 계면 격자 위 삼중대각 하나:
   `[1 + Δt c_ε sqrt(e^n)/l] e^{n+1} − Δt ∂z(K_e ∂z e^{n+1}) = e^n + Δt P`
4. `e^{n+1} = max(e^{n+1}, e_min)`. 표면 계면은 Dirichlet `e_s = e_bb · u_*²`, `u_*² = |τ|/ρ_0`;
   바닥 계면과 마른 계면은 `e_min`.
5. `K_m, K_h` 를 새 `e` 로 갱신 → **이 스텝의** §7.4 삼중대각 계수(`tri_m`, `tri_b`), `q`,
   `K_u`, `K_v` 와 (θ 스킴이면) Helmholtz 연산자 전 레벨을 **재구성**한다.

상수 (config `[physics3d_v06]`, 값은 Gaspar 1990):
`c_k = 0.1`, `c_ε = 0.7`, `Pr_t = 1`, `z_0 = 0.1 m`, `e_min = 1e-6 m² s⁻²`, `l_min = 0.01 m`,
`e_bb = 3.75`, `κ_vK = 0.4`, `N²_min = 1e-8 s⁻²`, `mxl = 'integral'`,
배경 `ν_b = physics3d.nu`, `κ_b = physics3d.kappa`.

`closure = 'none'` 이면 v0.5 와 **비트단위 동일**해야 한다 (V6-4).

### 11.3 3차 이류 (`advection = 'up3' | 'up3_tvd'`)

van Leer κ-스킴, κ = 1/3 (MITgcm 이류 33 / ROMS UP3 와 같은 3차 상류편향 면 보간).
동쪽 면 `i+1/2`, 이류속도 `u[i]`:
```
u[i] > 0 :  Cface = C[i]   + ¼[ (1−κ)(C[i]   − C[i−1]) + (1+κ)(C[i+1] − C[i]  ) ]
                  = ( −C[i−1] + 5 C[i] + 2 C[i+1] ) / 6
u[i] < 0 :  Cface = C[i+1] − ¼[ (1−κ)(C[i+2] − C[i+1]) + (1+κ)(C[i+1] − C[i]  ) ]
                  = ( 2 C[i] + 5 C[i+1] − C[i+2] ) / 6
```
`y`, `z` 방향은 같은 식. 플럭스와 발산은 §9.2·§10.4 그대로(면 두께 `dz3u`, 면 마스크).

**벽·바닥 처리:** 스텐실의 먼 셀(`i−1` 또는 `i+2`, 연직은 `k−2`/`k+1`)이 마른 셀이면 그 면은
**`upwind1` 로 강등**한다. 표면 계면은 §10 과 같이 `Cface_z[0] = C[0]`.

**제한자 (`up3_tvd`)**: Sweby 형 TVD 를 κ-스킴에 적용 (Superbee).
```
r = (C[i] − C[i−1]) / (C[i+1] − C[i])            (u>0; 분모 0 이면 r = 0 로 두고 Cface = C[i])
φ(r) = max( 0, min(2r, 1), min(r, 2) )
Cface = C[i] + ½ φ(r) (C[i+1] − C[i])
```
(u<0 는 대칭). 제한자는 분기 비용 축이다 — 정확도 차수는 매끄러운 해에서 2 로 떨어지며 그것이 측정
대상이다.

**운동량:** 같은 면 보간을 `u`, `v` 에 적용한다. §9.2 의 `ubar[i]`(셀 중심 u)는 `u[i−1], u[i]` 의
평균 대신 이류속도 `ubar_c` 의 부호에 따른 κ-보간으로, `ubar_y`, `ubar_z`, `vbar_x`, `vbar_z` 도
같은 규칙으로 바꾼다. 이류속도(`vbar`, `wbar`)의 정의는 §9.2 그대로.

## 12. 다중 장치 분할 (E19, spec v0.6 부록)

**범위.** 노드 안의 GPU 여러 장에 하나의 문제를 나눠 싣는다. 스킴은 양해 forward–backward(`fb`)만: θ-법은 분산 타원 솔버가, split-explicit 은 부분스텝마다 halo 교환이 필요하므로 이 절의 범위 밖이다(docs/41).

**분할.** $y$ 방향 1-D 슬랩. 장치 $g$ 는 전역 행 $j_0^{(g)} \le j < j_1^{(g)}$ 를 소유하고(연속, 겹침 없음, $\sum (j_1-j_0) = n_y$), 양쪽에 깊이 $H$ 의 halo 행을 붙인 확장 슬랩 $[j_0-H,\ j_1+H)$ 를 저장한다. 전역 행 인덱스는 $n_y$ 로 주기적으로 감싼다(닫힌 벽은 마스크가 처리하므로 halo 데이터는 항상 유한한 값이면 된다).

**정적 배열.** 지형·마스크·층두께 등 정적 배열은 전역 도메인에서 한 번 만든 뒤 행 단위로 잘라 넣는다(각 장치에서 다시 만들지 않는다 — 슬랩 경계에서 벽 조건이 잘못 생기는 것을 막기 위해).

**스텝.** 각 장치는 확장 슬랩 전체(halo 포함)에 대해 단일 장치 스텝을 그대로 실행한다. 스텝 뒤 상태 배열 — $u, v, b$ (또는 $T, S$), $\eta$, 그리고 폐쇄를 쓰면 $e$ (TKE)·$\nu_v$·$\kappa_v$ — 의 halo 를 이웃의 소유 행에서 복사해 갱신한다(장치 간 peer 복사; 스텝당 1회).

**정확성 조건.** 한 스텝 안에서 상태 → 새 상태로 가는 스텐실 연쇄의 총 반경을 $L$ 이라 하면 $H \ge L$ 일 때 소유 행의 결과는 단일 장치 실행과 **비트 단위로 같다**(셀 단위 연산의 순서가 같고 전역 환산이 없으므로). 게이트: `ndev = N` 의 상태 파일과 `ndev = 1` 의 상태 파일을 비교해 최대 절대차 0 을 요구한다(R2 의 $10^{-12}$ 보다 강한 조건). 기본값 $H = 16$; 3차 이류(반경 2)·연직속도·평균 연산자의 연쇄를 넉넉히 덮는다.

**보고.** 벽시계는 모든 장치의 스텝과 halo 교환·동기화를 포함한 값이다. 장치당 소유 행 수 $n_y/N$ 이 $H$ 보다 작으면 실행을 거부한다.

**다중 노드 변형 (MPI).** 같은 분할을 랭크마다 GPU 한 장으로 실행하는 MPI 드라이버(`cfd_exp3d5_cuda_mpi.cu`)는 halo 를 `MPI_Sendrecv` 로 교환한다 — 고정 호스트 메모리를 거치는 경로(기본)와 장치 포인터를 직접 넘기는 CUDA-aware 경로(`--device-mpi`) 둘 다 같은 정확성 조건($H \ge L$, 소유 행 비트 동일)을 만족해야 하며, 게이트는 두 경로 모두에 대해 단일 장치 상태와의 최대 절대차 0 을 요구한다. 보고하는 벽시계는 랭크별 시간의 최댓값이다.
