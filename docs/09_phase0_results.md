### 1.1 코리올리 처리의 검증 (설계 결정의 근거)

| 설정 | 관측 차수 | 1주기 후 진폭비 (nx=32) |
|---|---:|---:|
| `n_picard=2, θ_c=0.5` (사다리꼴) | **2.00** | 1.000481 |
| `n_picard=1` (명시적 코리올리) | **1.03** | **1.174** (17% 증폭) |

명시적 코리올리는 차수를 1차로 떨어뜨릴 뿐 아니라 **진폭을 증폭**시킨다.
스펙 §3.1의 Picard 반복은 장식이 아니라 2차 검증의 전제조건이다.

## 2. **핵심 결과: θ가 지불하는 정확도 대가** (RQ1 / 문헌 L2)

1 파주기 후 `amp_ratio` = 수치 진폭 / 해석 진폭. **1.0 = 무감쇠.**

| nx (dx) | CFL | θ=0.5 | θ=0.6 | θ=1.0 |
|---|---:|---:|---:|---:|
| 32 (312 km) | 0.50 | 1.000481 | **0.9013** | 0.5982 |
| 64 (156 km) | 0.50 | 1.000064 | **0.9484** | 0.7679 |
| 128 (78 km) | 0.50 | 1.000008 | **0.9735** | 0.8745 |
| 256 (39 km) | 0.50 | 1.000001 | **0.9867** | 0.9353 |

> **정량화된 답:** SCHISM류가 강건성을 위해 쓰는 **θ=0.6은, 파를 격자당 ~10셀로 해상할 때
> 파주기당 약 5%, 격자당 ~5셀이면 파주기당 약 10%의 진폭을 잃는다.**
> θ=0.5는 같은 조건에서 손실이 5e-5 이하다.
> 완전음해(θ=1.0)는 파주기당 최대 40%를 잃어 **장주기 파 전파에는 사용 불가** 수준이다.
>
> 이 감쇠는 `dt`를 줄여도 `dx`를 줄여야만 사라진다(1차 수렴) — 즉 **θ>0.5의 대가는
> 시간스텝을 줄여 회수할 수 없다.** 이것이 문헌 L2에서 지적한 빈틈의 정량적 답이다.

## 5. 오차 vs 비용 프론티어 (nx=100, DEV-ONLY 타이밍)

`L2_rel(η)` / wallclock [s] / 스텝당 [µs]

| CFL | fb (양해) | θ=0.5 | θ=0.6 | θ=1.0 |
|---:|---|---|---|---|
| 0.125 | 9.07e-3 / 0.671 | 9.26e-3 / 1.176 | 1.26e-2 / 1.156 | 4.30e-2 / 1.006 |
| 0.5 | 7.58e-3 / 0.172 | 1.07e-2 / 0.286 | 3.53e-2 / 0.248 | 1.58e-1 / 0.248 |
| 1.0 | 2.63e-3 / 0.088 | 1.53e-2 / 0.135 | 6.84e-2 / 0.127 | 2.93e-1 / 0.147 |
| 2.0 | **3.2e+8 (발산)** | 3.23e-2 / 0.070 | 1.28e-1 / 0.063 | 4.88e-1 / 0.074 |
| 8.0 | **7.9e-1 (발산 잔해)** | 4.17e-1 / 0.016 | 4.89e-1 / 0.014 | 9.74e-1 / 0.017 |
| 스텝당 비용 | **~1.93 ms** | ~3.2 ms | ~2.9 ms | ~3.1 ms |

### 읽는 법

1. **양해법은 CFL 2에서 정확히 발산**한다 → 스펙 §3.2의 안정한계
   `dt ≤ dx/(√2·c)` 가 실측으로 확인됨.
2. **스텝당 비용은 semi-음해법이 약 1.7배 비싸다** (FFT Helmholtz 1회 × Picard 2회).
   즉 semi-음해법이 이기려면 **CFL을 1.7배 이상 키워도 정확도가 버텨야** 한다.
3. **이 파(격자당 ~10셀 해상)에서는 그렇지 못하다.** 정확도가 dt에 민감해서
   CFL 1을 넘기면 오차가 급증하므로, 안정 영역 안에서는 **양해법이 파레토 우위**다.
4. semi-음해법이 이기는 구간은 **거친 정확도 요구(오차 > 10⁻¹)** 뿐이다.
5. **경고 — 과대해석 금지:** `fb`의 CFL=1 오차(2.6e-3)가 CFL=0.125(9.1e-3)보다 **작다.**
   이는 공간·시간 절단오차의 **부호가 반대라 상쇄**된 것이며 정확도 향상이 아니다.
   단일 CFL 지점 비교가 왜 위험한지 보여주는 사례 → 항상 스윕 전체를 본다.

### 이 결과의 유효 범위 (중요)

이 프론티어는 **감쇠 없는 단일 중력파 모드, 2D 선형, 마찰·이류 없음** 조건이다.
실제 해양모델에서 semi-음해법이 채택되는 이유는 여기에 없는 항들 때문이다:
- **연직 확산**의 `Δt < Δz²/2ν` 제약 (음해가 아니면 치명적) → Phase 2
- **천해에서의 표면중력파** — 얕은 곳일수록 `c` 대비 격자가 작아 CFL이 가혹 → Phase 2
- **경압/순압 모드 분리** 필요성 → Phase 1의 `split_explicit`
- 습윤/건조, 급격한 지형 → 범위 밖

> 따라서 **"Phase 0에서 양해법이 이겼다"를 일반화하면 안 된다.**
> 이는 오히려 **각 Phase에서 semi-음해법이 실제로 무엇을 사서 오는지**를
> 통제된 조건에서 하나씩 확인해야 한다는 근거다.
