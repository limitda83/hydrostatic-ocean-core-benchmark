# E10_lock_exchange_rpe

**질문/내용:** 락 익스체인지의 기준 위치에너지(RPE) 드리프트로 **가짜 혼합**을 재고, 그것이 시간적분 스킴과 이류 스킴 중 무엇에 의존하는지 가린다.

**보고서:** docs/27_lock_exchange_rpe.md

**노드:** 로컬

**상태:** **완료** (2026-09-14). docs/27 §4 가 열어 둔 세 확인을 측정해 종결했다 — (1) `upwind1` 은 연직 플럭스를 안 바꾼다(사실), (2) 추적자는 **실제 두께로 보존된다**(1.09e-08; 정지 두께로 재서 1.4e-5 누출로 보였던 것은 진단 오류), (3) 정렬 가중치가 답을 지배한다. 결론: `upwind1` 의 음수 드리프트는 실재하며 보존오차의 3500배다. 남은 것은 연직 이류 스킴 스위치(스펙 변경, 선택). 2026-09-14 에 정렬 기준레벨을 basin 의 hypsometry 로 고쳤다(구 상자 가정은 `rough` 에서 59 % 과대평가, N37). 스킴 순서는 불변.

**재현 명령:**
- `PYTHONPATH=. python3 tools/verify_rpe.py --nx 64 --nz 20 --steps 800`

**데이터 (`data/`):** `rpe_checks.json`(200 스텝), `rpe_checks_s400.json`, `rpe_checks_s800.json`, `rpe_checks_flat.json`, `rpe_checks_rough.json`(지형 대조) —
각각 이류 4종 × 시간적분 2종의 RPE 드리프트(정지/실제 두께 두 가중), 추적자 상대변화, |η|max.
RPE 드리프트는 **정확도 진단이라 하드웨어 무관**이므로 개발기에서 재는 것이 R7-1 에 어긋나지
않는다(R7-1 이 금지하는 것은 그 기계의 **시간** 수치다). 이 실험은 시간을 보고하지 않는다.

**코드 리비전:** e79be85 (이 대장을 만든 시점; 실험 시점의 SHA 는 보고서/manifest 참조)
